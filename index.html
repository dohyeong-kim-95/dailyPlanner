GitHub Gist 연동 설정

📝 설정 방법:

  1. https://gist.github.com 접속
  2. New gist 클릭
  3. 파일명: planner-data.json, 내용: {}
  4. Create secret gist 클릭
  5. URL에서 ID 복사 (gist.github.com/.../[이부분])
  6. 토큰 생성 페이지 접속
  7. Generate new token (classic) 클릭
  8. gist 권한 체크 후 생성
입력한 내용은 이 브라우저에만 저장됩니다

💡 Gist 연동 안 하면 localStorage만 사용합니다 (기존 방식)
